**What and why.** The owner's read-only business overview that Jasil asked for on Slack (6 Nov 2026), first screen. It opens on **Last 30 days and All cities** and shows, for the filters chosen at the top:
- **Headline cards:** earned delivery revenue, completed deliveries, gross profit before overheads with the margin %, active drivers, deliveries per active driver-day, and revenue and margin per delivery. The first three compare with the previous period of the same length (sign, amount, percent, arrow; colour is never the only signal). A comparison that cannot be made says "Insufficient data" with the server's reason; a partly covered one passes the server's note on. A missing amount is "N/A", never zero.
- **Top cities:** ranked by revenue, deliveries or gross margin, each with its exact value, its share, and a bar that is only a picture of the text. "Show as table" gives the same data with headings and a caption. Choosing a city filters the whole page (cards and ranking) to it; choosing it again, "Show everything" or "Reset filters" is the way back.
- **Filters:** presets (Last 7 days, Last 30 days, This month, Last month, Custom), two dates for Custom (up to 1096 days: the pay run's 31-day limit is not inherited, and a longer range is explained on the page, not sent), the city, and the record source (daily, weekly or both). They live in the address (`?preset=…&cities=…&source=…`), so a view can be shared and Back works; anything invalid in the address is ignored and the defaults show.
- **Honesty:** the page says when the data was made ("Data as of"), how far the delivery records go, how many records have no stored amounts yet, the server's own notes, and that gross profit before overheads is not net profit and revenue is not cash received. Each card's (i) tip reads the shared definition from `/admin/insights/definitions`, the same file the Claude connector reads. No figure is ever made up: on an error or while loading there are no figures, only a skeleton or a message with "Try again".
- **Access:** the route is inside the super admin guard and lazy-loaded, the menu entry is for the super admin only, and the server refuses everyone else (#229). The page only issues GET requests to `/admin/insights`; it cannot change pay, claims or payments, or call Everee.

**How it is built.** The filters hook and the report hook answer "which question is this answer for": a new question shows loading (never the old figures), a replaced request is cancelled, and a late answer for an earlier question is dropped. Pure helpers (`insightsDates`, `insightsFormat`) hold the date and number rules and are tested alone.

**Database / config / dependencies:** None. No new package: the bars are plain elements, and the chart library comes with the trend charts (Recharts, to be checked then). The page is a separate lazy chunk, about 22 kB (7 kB gzipped); the main bundle grew by about 0.2 kB (the route and the menu icon). **Money impact:** None; nothing is calculated here, figures are shown as the server sent them.
