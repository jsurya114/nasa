# A refunded claim penalty nets out

The carrier's Claims Detail sheet can hold a penalty and, later, a "Prior Period Claim Refund" for the same waybill: for one driver, a lost parcel at -13.86, a tracking interruption at -40 and a +13.86 refund of the lost parcel. The carrier's own driver summary charges the driver 40. NASA charged 67.72, because the owner-confirmed rule "the deduction is the absolute value" also turned the +13.86 refund into a 13.86 deduction.

The parser now treats a positive amount whose remarks say "Refund" as money given back, never a charge. It is set against the penalty for the same waybill, in cents: a penalty covered in full is dropped, a part refund leaves the rest, one refund is used once, and a refund with nothing to cancel in the file deducts nothing and is reported as a row note (it does not credit the driver). Every other positive amount, with no "Refund" in the remarks, is still a deduction, so the absolute-value rule holds for anything else. Across all eight carrier sheets on hand, every positive row says "Prior Period Claim Refund" and every penalty is negative.

An upload also retires copies an earlier upload stored: the penalty a refund cancels in full, and a refund the old rule kept as a charge (this city only). A retired claim is marked superseded like an amended one, so nothing treats it as owed. A claim already taken from a driver on a pay run is left alone and counted (`refundedAlreadyTaken`): taking money back is the ledger's refund, never done silently. Rules version is now `claims-2026-11-10`.

Validation: parser and rule tests pass (29), a new database test covers retiring (own city only, unrelated claim kept, second run changes nothing). The real SHV workbook, run through the upload recorder in a transaction that was rolled back, leaves the driver owing 40; the DFW workbook's 8.54 refund cancels its lost parcel and its 8.00 refund (on an exempt tracking interruption) deducts nothing. Not run on production data. Existing database tests in `claimsStore.test.js` fail on a local copy that already holds claims, with or without this change.
